# 1. wordflow-game-design — ระบบเกมหลัก (Adventure Redesign)

## เกมนี้คืออะไร

WordFlow คือเกมฝึกอ่านภาษาไทยสำหรับเด็กที่มีปัญหาการเรียนรู้ (LD) โดยเฉพาะ
dyslexia ดีไซน์นี้มาแทนที่ระบบเดิมที่เป็น point-and-click แบบ "daily quest"
เพราะทีมคลินิกดูแล้วอนุมัติแนวคิด แต่ติงจุดเดียวสำคัญมาก คือ **เด็กไปเร็วเกินกว่า
ที่จะเชี่ยวชาญจริง** และระบบ point-and-click เดิมรู้สึกเหมือนงานบ้าน (chore)
ไม่สนุก

## Loop หลักของเกม (การเจอด่าน 1 ครั้ง)

ลำดับเต็ม:

> หยุดเจอปัญหา → ต่อคำเป้าหมายจาก tile พยัญชนะ/สระ (เช่น ย + า → ยา) →
> ออกเสียงพูด → ระบบให้คะแนน PAR + latency → เอฟเฟกต์รางวัลภาพ → เดินต่อ
> ทำแบบนี้ 5 ครั้ง → เข้าสู่กลางคืน

รายละเอียดแต่ละส่วน:

- **เดินอัตโนมัติ (auto-run):** ตัวละครวิ่งไปทางพื้นที่หลักของ region เองโดย
  อัตโนมัติ ให้ความรู้สึกแบบเส้นทาง Pokémon สมัยก่อน **ผู้เล่นไม่มีสิทธิ์บังคับ
  การเคลื่อนที่เลย** — ทำแบบนี้ตั้งใจ เพื่อตัดภาระทางความคิดเรื่องการเดินเรือ/
  นำทางออกไป (ดีต่อเด็ก LD) และทำให้เด็กทุกคนเจอเส้นทางเดียวกัน ข้อมูลทาง
  คลินิกจะเทียบกันได้ระหว่างผู้เล่นและรอบเล่น
- **สุ่มเจอด่าน (random encounter):** ปัญหาที่ต้องแก้เพื่อไปต่อ เช่น
  - ชาวบ้านป่วย → ต่อคำ **ยา** (medicine)
  - มอนสเตอร์ → ต่อคำ **ปา** (attack spell)
- **การแก้ปัญหา = การต่อคำ (จุดขายหลักของเกม):** เด็กประกอบคำเป้าหมายจาก
  tile หน่วยเสียง/ตัวอักษรย่อย (เช่น ย + า → ยา) แล้วออกเสียงคำนั้น นี่คือ
  นวัตกรรมหลักของโปรเจกต์ — การต่อคำที่เด็กเป็นคนขับเคลื่อนเอง
- **การให้คะแนน (grading):** คำที่พูดจะถูกให้คะแนนผ่านระบบ phoneme accuracy
  assessment (PAR + Response Latency ผ่าน RevoiceAI) ยิงไปที่ backend
  endpoint `/grade` เกรด A = ความแม่นยำ 60-79%, เกรด B = มากกว่า 80% บวกมี
  โอกาสลองใหม่
- **รางวัล:** ถ้าสำเร็จ จะมีเอฟเฟกต์ visual reward (ไอเทมดรอป ประกายแสง
  เอฟเฟกต์เลเวลอัพ) แล้วเกมก็เดินต่อ
- **ข้อความน้อยที่สุดโดยตั้งใจ:** คำสั้นและใช้ไอคอนนำ เพราะกลุ่มเป้าหมายคือเด็ก
  LD/dyslexic การอ่านประโยคยาวไม่ใช่โจทย์ของเกม — โจทย์คือการต่อคำสั้นๆ
  แล้วพูดออกมา

## Phonics & การฟัง — การต่อคำต้องใช้หลายประสาทสัมผัส

การร่ายเวทจากคำ **ไม่ใช่แค่ต่อ tile เงียบๆ — ต้องได้ยินเสียงก่อนเสมอ**
นี่คือหัวใจสำคัญสำหรับเด็ก dyslexic เพราะจุดอ่อนของเขาคือการเชื่อมโยง
ตัวอักษร↔เสียง (grapheme↔phoneme):

- **ทุก tile ตัวอักษรออกเสียงเมื่อถูกใช้** พยัญชนะ/สระไทยแต่ละตัวมีเสียงของ
  ตัวเอง เด็กจะ*ได้ยิน*เสียงของแต่ละ tile ไม่ใช่แค่เห็นตัวอักษร (ย → /j/,
  ป → /p/, า → /aː/ ฯลฯ)
- **เด็กจะได้ยินคำเป้าหมายด้วย** — เสียงที่คำที่ต่อเสร็จควรจะเป็น ลำดับคือ
  เห็นตัวอักษร → ได้ยินเสียง → ผสมเสียงเป็นคำ → พูดออกมาเพื่อให้คะแนน
- ฝึกทั้งสองทิศทาง (เห็น→ได้ยิน และ ได้ยิน→พูด) ในด่านเดียว

### ตัวอย่างคาถา (พยัญชนะ + า)

| Tile | คำ | เสียง | ความหมาย/การใช้ |
|---|---|---|---|
| ย + า | ยา | yaa | ยา — รักษาชาวบ้านป่วย |
| ป + า | ปา | paa | ขว้าง/ปา — โจมตีมอนสเตอร์ |
| ม + า | มา | maa | มา |
| ต + า | ตา | taa | ตา (อวัยวะ) |
| ก + า | กา | kaa | อีกา |
| น + า | นา | naa | นาข้าว |

ชุด tile ออกแบบให้ data-driven คือคาถาใหม่ = แค่แถวข้อมูลใหม่ (คำเป้าหมาย +
การแยกเสียง + เสียงของแต่ละ tile) ไม่ต้องวาดภาพใหม่

## โครงสร้างเซสชัน — จุดแก้ปัญหาที่คลินิกติง

- **หลังจบ 5 ด่าน กลางคืนจะมาถึง จบวันนั้น** — บังคับให้เซสชันกลางวันยาว
  ไม่เกินช่วงสมาธิเด็ก (ประมาณ 15-30 นาที) และให้ข้อมูลคลินิกที่สะอาดกว่า
  เทียบกันได้ — จำนวนครั้งที่ให้คะแนนคงที่ต่อเซสชัน แทนที่จะเป็นการบดไม่มีจบ
- **ด่านช่วงกลางวันคือข้อมูลที่ใช้วัดผลทางคลินิก** อะไรก็ตามหลังกลางคืนไม่นับ
  รวมในการประเมิน
- **1 region กินเวลาหลายวันในเกม กฎเดียวคุมทุกอย่าง: ปลดล็อกหินเวทใหม่ได้
  มากที่สุด 1 ก้อนต่อคืน** — นี่คือส่วนลึกที่สุดของการแก้ปัญหา "เร็วไป" ที่
  คลินิกติง เพราะเด็กจะรีบไปข้างหน้าเกินความเชี่ยวชาญไม่ได้ ตัวอักษรใหม่จะ
  หยดเข้ามาทีละตัวต่อวัน และคำเก่าจะวนกลับมาซ้ำในระดับที่ยากขึ้น จบ region
  ด้วย**วันทบทวน/เตรียมตัวพิเศษอีก 1 วัน** (ไม่มีหินใหม่ — "ต้องพิสูจน์สิทธิ์
  ก่อนสู้บอส") ก่อนถึงบอส Region 1 = 5 วันด่าน (25 quest ที่ให้คะแนน) →
  วันบอส

## โหมดฝึกกลางคืน — ไม่มีเดิมพัน

หลังกลางคืนเด็กเล่นต่อได้ แต่**ไม่กระทบข้อมูลผลงานทางคลินิกช่วงกลางวัน**
เด็กร่ายคาถาจากคำที่ต่อ ใส่หุ่นฟาง/หุ่นซ้อม — เป็นการฝึกฟรี ความกดดันต่ำ
ที่ช่วยรักษาความสนใจโดยไม่ทำให้ชุดข้อมูลประเมินเสีย

## กลยุทธ์เรื่องทรัพยากรศิลปะ — แก้ปัญหาคอขวด

ปัญหาจริงของการผลิตคือมีคนคนเดียวทำงานศิลปะทุกชิ้นด้วยมือ ดีไซน์นี้แก้ด้วย
การทำให้**เนื้อหา data-driven ไม่ใช่งานศิลป์เฉพาะชิ้น**:

- Tile หน่วยเสียง/ตัวอักษร และ UI ต่อคำ**นำกลับมาใช้ซ้ำได้และเป็น
  data-driven** เพิ่มคำศัพท์ = เพิ่มแถวข้อมูล (คำเป้าหมาย + การแยกเสียง +
  ไอคอน) **ไม่ต้อง**วาดใหม่หรือสร้างฉากใหม่
- ทีมที่ไม่ได้ทำศิลปะสามารถผลิตเนื้อหา (รายการคำ ผังหน่วยเสียง ตารางด่าน)
  ไปพร้อมกันได้ **โดยไม่ต้องรอคนทำศิลปะ**

### รายการทรัพยากรขั้นต่ำสำหรับ demo

| ทรัพยากร | หมายเหตุ |
|---|---|
| ตัวละครวิ่ง | ท่าวิ่ง + ท่ายืนเฉย |
| ฉากหลัง region | parallax วนลูป; แบบกลางวัน + กลางคืนเปลี่ยนสี |
| ตัวละครในด่าน | ชาวบ้านป่วย 1 ตัว, มอนสเตอร์ 1 ตัว (สำหรับ demo) |
| UI tile หน่วยเสียง/ตัวอักษร | นำกลับมาใช้ซ้ำได้ ต้นทุนศิลปะต่อคำเกือบ 0 |
| แผงต่อคำ + ปุ่มไมค์/บันทึกเสียง | ภาพผลลัพธ์เกรด (A / B / ลองใหม่) |
| เอฟเฟกต์รางวัลภาพ | ไอเทมดรอป/ประกาย/เลเวลอัพ |
| โหมดฝึกกลางคืน | สไปรท์หุ่นฟาง + เอฟเฟกต์ร่ายเวท (ใช้ซ้ำจากเอฟเฟกต์ด่าน) |

## ทิศทางงานศิลป์ — โทนภาพ (แก้ไข 2026-06-13)

**ฟีดแบ็กที่ได้รับ:** ผู้รีวิวคนหนึ่งบอกว่าสไตล์ภาพ**มืดเกินไปสำหรับเด็ก** —
ดูหม่นและน่ากลัวนิดหน่อย ยอมรับตรงนี้ — "The Silence" ถูกวาดเอียงไปทาง
กลางคืน/สยองขวัญ แทนที่จะเป็นแสงกลางวันที่จางลง เจตนาแต่แรกคือโลกที่
**สีจางลงนิดหน่อย** ไม่ใช่โลกที่มืด หม่น หรือน่ากลัว หัวข้อนี้คือกฎแก้ไข
หลัก — เมื่อเจอคำว่า "desaturated" "gloom" "dread" "oppressive" "darkest"
ที่ไหนก็ตาม ให้อ่านผ่านกฎนี้ ไม่ใช่ตามตัวอักษร

**หลักการเดียว: The Silence ดูดความอิ่มตัวของสี (saturation) ไม่ใช่ดูด
แสง (light)** แยกสองแกนออกจากกัน — ความสว่าง/value ต้อง**สูงตลอด** มีแค่
ความอิ่มตัวของสีที่ลดลง ฉากที่ถูก Silence ครอบควรดูเหมือน**ภาพสีน้ำจางๆ
ใต้แสงกลางวันครึ้มฟ้าอ่อนๆ** ไม่ใช่เหมือนกลางคืน เงา หรือหมอกหลังมืด

- **ต้องสว่างไว้เสมอ** ฉากหลังสว่างโปร่ง (ฟ้าอ่อน สีครีมฟาง เทาอุ่นอ่อนๆ)
  ห้ามมีสีดำ ห้ามเงาหนัก ห้ามความมืดครึ้ม ถ้าฉากรู้สึก*หม่น*แปลว่าผิด
- **"Desaturated" = พาสเทลจางๆ ไม่ใช่เทาหม่น** คิดถึงสีซีดที่ยังเห็น
  ชัดว่าเป็น*สี* — อ่อนโยน แบบนิทาน เป็นมิตร ตอนได้รางวัลคืนสีจะทำให้สด
  และอุ่นกลับมา
- **ห้ามน่ากลัว** สัตว์/สิ่งของที่ถูกสาปดูเศร้า/ง่วง/เซื่องซึม/ไม่สบาย ไม่ใช่
  น่ากลัวหรือดูอันตราย เด็กควรอยาก*ช่วย* ไม่ใช่กลัว
- **ความตึงเครียดมาจากความนิ่งและความเงียบ ไม่ใช่ความมืด**
- **บอสคือจุดไคลแมกซ์ที่อ่อนโยน ไม่ใช่ฝันร้าย** หุ่นไล่กายักษ์อารมณ์เสีย/
  หม่นเศร้า ไม่ใช่มอนสเตอร์
- **บรรยากาศอ้างอิง:** โทนนิทานแดดใส / นุ่มแบบ Animal Crossing / ความอบอุ่น
  แบบ Pokémon ยุคแรก — "สีถูกหรี่ลง" แล้วเด็กเป็นคนหมุนกลับขึ้นมา

## ระบบ Region/Encounter

### กล้อง — 6 เฟส

- **World map:** มุมมองบนลงล่าง เลือก region ที่ปลดล็อกแล้ว
- **Hub:** มุมมองบุคคลที่ 3 *ตายตัว* อยู่หลังตัวนักเวท (ไม่ใช่ free-look —
  กล้องอิสระเพิ่มภาระการนำทาง + เสี่ยงเวียนหัวสำหรับเด็ก LD บางคน) บ้านฐาน
  ที่แสดงตัวอย่าง region
- **Travel:** มุมมองบนลงล่าง (แบบ Pokémon เก่า) — เหมาะกับเดินอัตโนมัติ
- **Encounter (กล้องโฟกัส "เหนือหนังสือ"):** ช่วงเวลาทางคลินิก = หน้าจอที่
  *เงียบที่สุด* — แผงหินเด่น ตัวละครที่มีปัญหาตัวเล็ก นกฮูกอยู่ข้าง ฉากหลัง
  หยุดนิ่งและสีจางลง (แต่ยังสว่างอยู่)
- **Boss:** โฟกัส บอสโผล่บนกรอบพร้อม heart HP และจุดอ่อนแบบภาพความหมาย
- **Reward/FX beat:** ไม่เกิน 3 วิบนเอฟเฟกต์เวท + คืนสีเฉพาะจุด แล้วเล่นต่อ

### ความคืบหน้าหินเวท (magic-stone progression)

หิน = ตัวอักษร (grapheme) เด็กเริ่ม region ด้วยหินไม่กี่ก้อน แล้วได้เพิ่ม
จากการทำซ้ำ เก็บหินครบของ region ปลดล็อกบอส **% ความคืบหน้า = หินที่เก็บ
÷ หินทั้งหมดของ region** ขับเคลื่อนทั้ง progression bar ที่แสดงตลอดเวลา
(สไตล์ Bookworm Adventures) และการคืนสีของ hub **เซฟอัตโนมัติที่จุดล่าสุด**
(ไม่มี waypoint — ผู้เล่นเดินเองไม่ได้) Region 1 ไปจาก 3 → 7 หิน

### Content engine — สร้างหลายด่านจากคำน้อย

หลักการ "คำเดิม สถานการณ์ใหม่ ความช่วยเหลือน้อยลง":
1. หลาย**บริบท**ต่อคำ (ความกว้าง, data-driven)
2. **scaffold แบบจางหายไป 2 โหมด** — **Supported** (เจอครั้งแรก + ซ้ำช่วงแรก:
   ปุ่ม "ฟังเสียง" นกฮูกพูดคำเต็มตอนเห็นครั้งแรก แต่ละ tile พูดเสียงตอนวาง) →
   **Recall** (ซ้ำรอบหลัง ปิด hint ก่อนต่อคำทั้งหมด — การผ่าน Recall คือจุดที่
   สร้างความเชี่ยวชาญจริง)
3. รูปแบบ **Echo** (โจทย์เสียงอย่างเดียว ไม่มีภาพ) สำหรับฝึกหู แยกอิสระจาก
   Supported/Recall จับคู่กับโหมดไหนก็ได้

Tile **เริ่มอยู่ใน tray เสมอ** — ไม่เคยวางไว้ในช่องล่วงหน้า — เรียงลำดับ
คงที่ ไม่สลับ; tile สลับ/ตัวหลอกเป็นกลไกที่ใช้เฉพาะ**บอส** (ยกเว้นตัวหลอก
ก 1 ตัวใน Region 1) Region 1 สร้าง **25 quest** จาก 7 คำ ตลอด 5 วัน โดย
ไม่ต้องเขียนโค้ดใหม่

### ผลลัพธ์ของด่าน — ตัดสินจากคำที่ต่อ (การออกเสียงไม่เคยถูกลงโทษ)

เด็กต่อคำจากหิน นกฮูกสะท้อนกลับว่าต่อคำอะไร (post-build echo) แล้วเด็กพูด
ออกเสียง `POST /grade` (PAR + latency) ยิงทุกครั้งที่ลอง — ถูก, ไม่ใช่คำจริง,
หรือคำจริงแต่ผิด — เพื่อเก็บข้อมูลคลินิก มันไม่เคยบล็อกหรือหน่วงเกมเพลย์
สาขาการเล่นตัดสินล้วนจาก*สิ่งที่ต่อ*:

- **ต่อคำเป้าหมายถูกต้อง** → เอฟเฟกต์เวทเต็ม ด่านผ่าน **+1 เลเวล** (1 quest
  = 1 เลเวล) เกมเดินต่อ ไม่มีการลองออกเสียงซ้ำ
- **คำที่ไม่มีความหมาย (non-word)** → ควันดำ + เสียงพลาดเบาๆ + นกฮูกบอก
  "ลองอีกที" → กลับไปหน้าหนังสือเวท ไม่มีผล แท็ก `outcome: non_word`
- **คำจริงแต่ไม่เกี่ยว** → เล่นเอฟเฟกต์เวทของตัวเองแต่ไม่มีผลต่อด่าน + นกฮูก
  "ลองอีกที" แท็ก `outcome: wrong_word`

**เฟสที่ implement แล้วใน Unity (2026-06-17):** ตัวควบคุมต้นแบบ
(`WordBuildEncounterController`) รันเป็น phase machine:

> intro cutscene → **Build** (แตะ tile จาก tray→slot) → **Confirm**
> (ทบทวนคำที่ต่อ; ดึง tile กลับมาแก้ได้) → **post-build Echo** (นกฮูกพูด
> สิ่งที่ต่อ เสมอ) → **Mic** (เด็กแตะเพื่อพูด) → `/grade` ยิงแบบมองไม่เห็น
> → แยกสาขาตามสิ่งที่ต่อ: **ถูก/เหมาะสม** → เอฟเฟกต์เวท + outro + "+1 เลเวล";
> **ผิดคำ/ไม่ใช่คำ** → กลับไป Build "ลองอีกที"

### ลองผิดลองถูก: คำผิดเผยความหมาย (2026-06-20, ยืนยัน 2026-07-08)

คำจริงแต่ผิด → **เผยความหมายของคำนั้น** ก่อนส่งเด็กกลับไปลอง เพื่อให้ความ
ผิดพลาด*สอนบางอย่าง* ต่อ กา (อีกา) ตอนที่ด่านต้องการ ปา → เด็กเห็น/ได้ยิน
ว่า กา หมายถึงอะไร แล้วลองใหม่ ต้องมี**หินตัวหลอก ก ใน tray** (Region 1 มี
ตัวหลอกตัวเดียวนี้) echo หลังต่อคำจะสะกดทีละตัวแล้วผสม — ปา = "ปอ อา ปา"

### การให้คะแนนการสะกดเสียง (ตัดสินใจ 2026-06-29)

เด็กพูด**เต็ม ปอ อา ปา** ที่ไมค์ เพราะการผสมเสียง*คือ*ทักษะการถอดรหัส และ
บันทึกเสียงเต็มมีประโยชน์ทางคลินิกกับหมอมากกว่า วิธีแก้: ให้คะแนนเทียบกับ

## Challenge & pressure system — "The Silence สู้กลับ" (2026-07-08)

มาจาก feedback กรรมการ/ที่ปรึกษา (7 ก.ค.): *เกมเพลย์ง่ายเกินไป — ต้องสนุก
และความท้าทายคือแหล่งความสนุกที่ใหญ่ที่สุด เพิ่มเวลาเข้าไป* หลักการ 3 ข้อ:

1. **แรงกดดันจริง เล็งไปที่เนื้อเรื่อง ไม่ใช่คำตัดสินการอ่าน** เด็ก LD
   ความวิตกกังวลบีบ working memory ซึ่งเป็นจุดอ่อน dyslexic ดังนั้นเดิมพัน
   ต้องขู่*ผลลัพธ์ของเกม* ไม่เคยตราหน้าการอ่านว่าล้มเหลว
2. **ความสูญเสียต้องรู้สึกได้** เห็นชัด แต่**กู้คืนได้เสมอด้วยความพยายาม**
3. **ความยากและการสอนเดินบนแกนเดียวกัน** กลไกความท้าทายเองสร้างการอ่านซ้ำ

> **หมายเหตุ:** กลไก smoke clock ที่ละเอียดที่สุด (spec สุดท้าย) อยู่ใน
> section 4 (handoff 2026-07-09) — ตัว handoff ใหม่ยกเลิก "3 smoke stages"
> เดิม เปลี่ยนเป็น `smokeT` ต่อเนื่อง และเปลี่ยน "ของขวัญแยกชิ้น" เป็น
> "ตัวสัตว์เองคือรางวัล"

### นาฬิกาควัน (smoke clock) — แรงกดดันเรื่องเวลา ในรูปเนื้อเรื่อง

ศัตรูสากลคือ **The Silence เอง** ระหว่างเฟส Build **ควัน silence สีซีดคืบ
เข้ามาบนหน้าหนังสือ** — ควันเดียวกับที่ป้องกันบอส ทุกด่านจึงปูเรื่องสู่บอส
- ควันคืบช้าๆ ตาม**เวลา** (นาฬิกา diegetic ไม่มี HUD)
- เพลงตึงขึ้นเมื่อควันหนา ต่อคำเสร็จ**ก่อนควันปิด** = ได้**ของขวัญ**
- แผนที่ยังมีสีสัน แรงกดดันอยู่**บนหน้าหนังสือเท่านั้น**
- **ไม่มีทางแพ้:** ควันไม่เคยปิดช่อง ไม่เคยทำให้ tile แตะไม่ได้

### กฎการ Build

- **ล็อกช่องตามลำดับอ่าน:** วาง tile ซ้าย→ขวา, ที่วางแล้วล็อก ("หมึกแห้ง")
  ดึงกลับเสียความคืบหน้าควัน
- **ต่อผิด ไม่ใช่คำ** → ควันพุ่ง (smoke surge) กลืนหินกลับ tray
- **ต่อผิด แต่เป็นคำจริง** → ครั้งแรก: เผยความหมาย ควันหยุดชั่วคราว; ซ้ำ → surge

### Flow — เพดานสำหรับผู้เล่นเก่ง

วาง tile ถูกและเร็วสร้าง **Flow** — หน้ากระดาษเรืองทอง เพลงซ้อนชั้น ร่ายตอน
Flow เต็มได้เอฟเฟกต์ทองระเบิดพิเศษ ลังเล/ผิด → Flow ลดลง ไม่มีอะไรถูกริบ
(เพดานให้ไล่ตาม เด็กช้าไม่เจอโทษ)

### ของขวัญ — เดิมพันที่พลาดได้

- เคลียร์**ก่อนควันปิด** → ได้ของที่ระลึก (collection book) ช้าไป → ยังผ่าน
  ยังได้เลเวล แต่**ไม่ได้ของขวัญ** สูญเสียจริง ไม่มีความอาย
- **กู้คืน: night redo** — ทำด่านที่ยังไม่ได้ของขวัญซ้ำตอนกลางคืน redo
  บันทึกด้วย (แท็ก `night_redo`) ชุดข้อมูลคลินิกกลางวันกรองแยกได้สะอาด
- **เพื่อน — เลือกคู่หู:** ทุกเช้าเลือกเพื่อน 1 ตัว (Pokémon-follower เดินตาม
  ให้สกิล icon+number เช่น 🕐+5 ควันช้าลง; สร้างสกิลจริง 1 อัน ที่เหลือ
  ตกแต่ง ไม่มี rarity) โชว์วงเพื่อน ~6 ตัว **หมีเข้าร่วมหลังบอส R1** เก็บ
  Region-1 ครบ → **ตอนจบเทศกาลลับ**

## ตัวอักษรและคำ (ล็อกแล้ว)

- **หินเวท = 7 ตัวอักษร:** พยัญชนะ **ก ป ต ย ข** สระ **า ี**
- **7 คำที่สร้างได้:** กา (อีกา), ปา (ขว้าง), ตา (ตา), ยา (ยา), ขา (ขา),
  ตี (ตี), ปี (ปี)
- การสอน: สระ **า** รู้จักตั้งแต่ต้น; **ี** เข้ามาทีหลังบนพยัญชนะที่รู้จักแล้ว
  (ต→ตี); คู่เสียงคล้าย **ก /k/ กับ ข /kʰ/** แยกให้ห่างกัน (ก มาต้น ข ท้าย)

- **บอส (ที่ซ่อน):** ดราม่าสุด **ไม่ใช่มืดสุด** หมอกเงียบสีเทาซีด (ไม่ใช่ดำ)
  หุ่นไล่กายักษ์อารมณ์เสีย ไคลแมกซ์อ่อนโยน น่าตื่นเต้น ไม่น่ากลัว

## บอส — ชายฟางที่ถูกสาป (ร่างของ The Hush)

# 3. wordflow-story — เนื้อเรื่อง: "The Silence"

## ที่มา — "The Silence"

พลังชื่อ **The Silence** กลืนคำพูดและเสียงของโลก ที่ไหนคำหาย โลกตรงนั้น
**สีจางและเงียบ** — *สีถูกหรี่ลง ไฟยังเปิดอยู่* (สว่าง นุ่ม ไม่มืด ไม่น่ากลัว)
สัตว์ในนั้นง่วง/เศร้า/ป่วย ผู้เล่นคือ**นักเวทเด็ก**ที่**เวทมนตร์คือการพูด** —
**พูดคำออกมา คืนคำนั้นกลับมา** คืนสี เสียง ชีวิต บอสของแต่ละ region คือ
**ต้นตอของ Silence** ทำให้กลไกหลักเป็นรูปธรรม: **การพูดคือพลังที่รักษาโลก**

**เดิมพันส่วนตัว (2026-07-08):** หมู่บ้านฟางคือ**บ้านของนักเวทเอง** Silence
โจมตีที่นี่ก่อน ต่อหน้าเขา ทุกการรักษาใน R1 เป็นเรื่องส่วนตัว

4 จังหวะ (แต่ละจังหวะไม่กี่วินาที ขับเคลื่อนไอคอน/แอนิเมชัน ไม่มีข้อความ):

## การเล่าเรื่องแบบไร้คำพูด — กฎ

**ไม่จำเป็น**ต้องอ่านออกเพื่อตามเรื่อง เล่าผ่าน:

- **เอฟเฟกต์เวท** การร่ายสำเร็จทุกครั้งเป็นการระเบิดที่น่าพอใจ

**หลักการเล่า:** ทุก story beat ไม่เกิน 3 วินาที ขับเคลื่อนไอคอน/แอนิเมชัน
**ไม่เคย**ล็อกความคืบหน้าไว้หลังการอ่าน

## กฎที่สำคัญ (6 ข้อ)

1. **ต่อเนื่อง ไม่เป็นขั้น (continuous, never stepped).** ใช้ float ตัวเดียว
   `smokeT` วิ่ง 0→1 ภายใน 60 วินาที ขับ vignette + particle + พารามิเตอร์
   เสียงทั้งหมด — ขั้นแยกๆ (discrete stages) มองไม่ออกที่งบศิลปะของเรา
   **การเคลื่อนไหวตลอดเวลา**คือสัญญาณความเร่งด่วน ตั้งแต่วินาทีแรก จุดตัด
   (owl warning, gift cutoff) อยู่ในโค้ดเท่านั้น (เด็กไม่เห็น)
2. **เสียง (SFX) คือช่องแรงกดดันหลัก** (คุ้มสุด ถูกสุด): เสียงหัวใจเต้นได้ยิน
   ~10 วิ, เพลงเร่งจังหวะ, เสียงรอบข้างอู้อี้ลง ต่อคำที่ไม่ใช่คำจริง = ควัน
   **พุ่ง (lunge)** + เสียงสะดุด (+~20 วิ) การเผยความหมาย กา หยุดนาฬิกา
3. **เพดาน + ปล่อย (ceiling + release).** พอ `smokeT`=1 คำตัดสินล็อกเงียบๆ
   แล้วควัน**หยุด** (เป็นกรอบขอบหนา ไม่เคยแตะ tile/หิน) เสียง**สงบลง** เด็ก
   ที่อ่านช้าถอดรหัสเสร็จอย่างสงบ — ไม่มีวังวนแห่งความตาย (no death spiral)
   เรื่องราว: Silence ลงหลักปักฐานไปแล้ว แต่คำก็ยังรักษาได้อยู่ดี
4. **กฎของหิน (ถาวร): หินเวทไม่เคยหรี่แสง.** มันคือสัญลักษณ์พลังของเด็กเอง
   หรี่มัน = เล็งแรงกดดันไปที่การอ่านโดยตรง โลกอาจถูกควันคลุมได้ แต่หินสว่าง
   เสมอ (เคยคิดทำ "หินเป็นเกจเชื้อเพลิง" แล้วปัดตกไป)
5. **2 สกิน 1 engine:** สัตว์ที่กำลังจม = เสียงร้องของมันดังเรียกแล้วค่อยๆ
   อู้อี้ลงเมื่อควันสูงขึ้น; ผู้บุกรุกที่ยังมีชีวิต (หมี) = เสียงคำรามใกล้เข้า
   มา + สั่นสะเทือนเบาๆ ได้ยินแต่ไม่เห็นตัวบนหน้าจอต่อคำ
6. **คำตัดสินเกิดหลังกล้องโฟกัส** ในฉากโลก (world scene) หน้าจอต่อคำโชว์แค่
   นาฬิกา ไม่เคยโชว์ผลลัพธ์

## ภาคผนวก — เทียบ smoke clock: ดีไซน์ vs โค้ดจริงตอนนี้

โค้ดปัจจุบันมี `WordAssemblyTimer` = นาฬิกานับถอยหลัง **30 วิ โชว์ตัวเลข
MM:SS + เสียง beep ตอนเหลือ 10 วิ** ซึ่งเป็น **"raw timer" ที่ดีไซน์ปัดตก**

| | ตอนนี้ (ของจริง) | ดีไซน์อยากได้ (spec 9 ก.ค.) |
|---|---|---|
| หน้าตา | ตัวเลข 30→0 + beep | ควันซีด vignette คืบจากขอบ (`smokeT` 0→1) |
| เวลา | 30 วิ | 60 วิ |
| แรงกดดันหลัก | ภาพตัวเลข + beep | **เสียง** (หัวใจเต้น เพลงเร่ง อู้อี้) |
| ถึงเวลาหมด | ค้างไว้ (fail = TBD) | ควันหยุด เสียงสงบ ต่อได้เรื่อยๆ อดของ |
| รางวัล | ยังไม่มี | ตัวสัตว์มาเป็น pet + ลงสมุด (ช้า = เงาดำ) |

**สิ่งที่ต้องเปลี่ยน (ไม่ต้องรื้อ timer เดิม):**
1. เปลี่ยนหน้าตา: ซ่อนตัวเลข → เอา sprite ควันซีดมา lerp ด้วยค่าเวลาเดิม
2. ยืด 30 → 60 วิ
3. เอา beep ออก → ใส่ audio ramp (หัวใจ/เพลง) แทน
4. ตอนหมดเวลา: ควันหยุด + ล็อก verdict เงียบ (ไม่ fail)
5. ต่อ verdict flag → world scene (ได้สัตว์ / สัตว์เดินจาก + เงาดำในสมุด)
